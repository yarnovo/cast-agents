# REQ-001 · + POST /api/agent/run · 接 harness 新 run() 多轮 tool use loop API

## 描述

上游 `akong-agent-harness@fc8c576` (#1 已 merge · 5-7 拍) 已落地 `runtime.run()` 新 API:
- 多轮 tool use loop · sync 一次性返 `RunResult` (老板 5-8 砍 streaming)
- 配套 `AgentDef` / `Session` (RdsSession 走 cast-api `/api/chat_messages`) / `LLMClient` (OpenAICompatibleClient)
- session_id 由 caller 自管 · 跨 FC invoke sticky 续上下文

cast-api `chat_messages` 表 + 3 endpoint (POST/GET/DELETE) 已 prod live · 链路 ready。
